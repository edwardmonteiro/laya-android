# Perception Local

Experimental, fully local Android perception HUD.

Current V0 scope:
- rear CameraX preview;
- GPS speedometer in km/h;
- linear-acceleration ego-braking signal;
- experimental red/yellow/green light color detection;
- experimental paired brake-light cue;
- central HUD reticle;
- separate application id: `com.edward.perception.local`.

This is a prototype perception aid, not a certified ADAS or safety system.
